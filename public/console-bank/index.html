CUEs

Group by
A CUE is the signed execution envelope for one tool, keyed by (tool, group). It has two layers: a base profile for the tool (egress allow-list and onboarded MCP servers) and an intent for the execution (DLP rules and custom permissions). Everything else is blocked. Writable paths are passed at launch with --src, so they are not part of the CUE. A device belongs to one group, so exactly one CUE resolves for any tool it runs.
